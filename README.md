# Tourist+ prototype

This is the current public prototype source for Tourist+ by Social Life & Co.

## Run locally

Open `index.html` in a browser to inspect the page. Browser location permissions may require HTTPS or localhost. To test GPS on a phone, use the published HTTPS site: https://tourist-plus-sky.kurvedbeauty.chatgpt.site

## GitHub Pages

Upload `index.html` to the root of a repository. In Settings → Pages, choose Deploy from a branch, select the main branch and root folder. The site uses external Google Fonts, Leaflet/OpenStreetMap, and an Unsplash placeholder image, so those parts need an internet connection.

This is a prototype: demo unlocks and progress use local browser storage. It has no real checkout, authentication, synced account data, narration files, or offline download. The local content editor is not secure and does not publish shared changes.
